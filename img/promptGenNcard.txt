คุณคือผู้เชี่ยวชาญด้านการออกแบบ LINE Flex Message JSON ระดับมืออาชีพ 

โปรดสร้าง Flex Message JSON สำหรับส่งข้อความเชิญชวนสร้าง "นามบัตรดิจิทัล (Digital Business Card)" โดยมีรายละเอียดดังนี้:

1. ชื่อหลักสูตร: [ระบุชื่อหลักสูตรที่นี่ เช่น: GeoAI เพื่อการเกษตรแม่นยำสูง (Smart Agriculture) รุ่นที่ 1]
2. ลิงก์ปุ่มกด (URI): [ระบุ URL ที่นี่ เช่น: https://liff.line.me/2011099349-XctZrigM?room=GeoAI_รุ่นที่_1]

[ข้อกำหนดในการสร้าง Flex Message]
1. **การเกลาภาษา (Body Text):**
   - ปรับแต่งข้อความทักทายและรายละเอียดให้เป็นทางการ สละสลวย เหมาะกับวงการวิชาการและธุรกิจ
   - ข้อความเน้นการเชิญชวนเรียน เพื่อนสมาชิก และท่านอาจารย์ ร่วมสร้างนามบัตรดิจิทัลเพื่อแนะนำตัว สร้างเครือข่ายความร่วมมือ และประชาสัมพันธ์สินค้า/บริการ

2. **ธีมสีและรูปภาพ Header:**
   - คัดสรรรูปภาพ Header (Unsplash URL) และธีมสี (Background & Accent Color) ให้สอดคล้องกับ "ชื่อหลักสูตร" โดยเน้นสไตล์ Futuristic, High-Tech, Professional (เช่น พื้นหลังโทนเข้ม #0A192F ตัดกับสีเน้นประเภท Bright Cyan/Neon Green/Electric Blue ตามบริบทของหลักสูตร)

3. **มาตรฐานไวยากรณ์ JSON และความถูกต้อง:**
   - **ข้อห้ามสำคัญ:** ห้ามใส่ Property `lineSpacing` ใน Component ประเภท `text` โดยเด็ดขาด เพื่อป้องกัน Error บน LINE Simulator และอุปกรณ์ต่างๆ
   - ใช้เฉพาะ Standard Properties ของ LINE Flex Message เท่านั้น
   - ต้องตรวจสอบโครงสร้าง JSON ให้ถูกต้อง 100% สามารถนำไปวางใน LINE Flex Message Simulator ได้ทันที
   - หาก URL ของปุ่มมีอักขระภาษาไทยหรืออักขระพิเศษ ให้ทำ URL Encoding ให้เรียบร้อย

4. **โครงสร้างการจัดวาง (Layout Structure):**
   - **Header:** รูปภาพแบบ Full-bleed พร้อม Linear Gradient Overlay ทับด้านล่าง ใส่ชื่อ Tag หลักสูตรภาษาอังกฤษตัวพิมพ์ใหญ่ และชื่อหลักสูตรภาษาไทย
   - **Body:** 
     - หัวข้อย่อย "ขอเชิญสร้างนามบัตรดิจิทัล" พร้อมไอคอน
     - ข้อความทักทาย "เรียน เพื่อนสมาชิกและท่านอาจารย์"
     - ข้อความรายละเอียดความสำคัญของการสร้างนามบัตร
     - เส้น Separator
     - รายการสิทธิประโยชน์/จุดประสงค์ 2 ข้อ พร้อมไอคอน Emoji หน้าข้อ
   - **Footer:** ปุ่มกดสไตล์ Primary สีตัดกับพื้นหลัง ความสูงระดับ `sm` ระบุข้อความ "สร้างนามบัตรดิจิทัล"

5. **รูปแบบผลลัพธ์:**
   - แสดงผลโค้ด JSON อยู่ใน Code Block ที่พร้อมคัดลอกไปใช้งานทันที
